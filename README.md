# durhack-2026

A browser simulation where trains run themselves, share track through local locks, and keep moving at reduced speed when the radio or the control centre fails. Built for the Neptune North challenge at DurHack 2026.

- [docs/design.md](docs/design.md) is the agreed design and the shared types.
- [CLAUDE.md](CLAUDE.md) is how we work in this repo.
- The issues list is the task board.
